# Security Policy

This repository hosts the GitHub profile README for [@gsantana212](https://github.com/gsantana212). It contains no production code and no executable artifacts — security reports for SkillHub, Ada, or any other product should be filed against the relevant project repository.

## Reporting a vulnerability

If you discover a security issue in a SkillHub / Ada product, please **do not** open a public issue. Instead:

- Email: **gsantana212@** (replace `@` with the appropriate domain — see [skillhub.shop](https://skillhub.shop) for the current contact address).
- Include: affected repo + commit SHA, reproduction steps, impact assessment.
- Expected response: acknowledgement within 72 hours; triage within 7 days.

## Supported versions

This `.github` profile repository is always considered current — there are no versioned releases to backport security fixes to.

## Disclosure policy

We follow coordinated disclosure: we will work with you to confirm and patch the issue before any public announcement. Please give us a reasonable window (default 90 days) before disclosing.
